---
name: Web recovery guardrails
description: 自己修復Web検索は通常回答だけを対象にし、誤認検出後も1ターン1回で初稿を保持する。
---

通常チャットでWeb検索不能の誤認を検出した場合だけ、検索・根拠付き再回答・既存の根拠検証を連鎖させる。翻訳モードでは発火させず、失敗時は初稿を復元する。false denial判定と翻訳スレッドresetは共有policyを単一の判定元にする。

**Why:** 翻訳の監査境界を壊さず、検索障害や監査障害でユーザーが見えていた回答まで失わないため。

**How to apply:** 新しい検索自己修復を追加するときは、明確な検出条件、1ターン上限、SSEの表示リセット、初稿復元、SSRF済み検索経路の再利用を維持する。
