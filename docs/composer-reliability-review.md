# 入力・添付・モバイル操作の改善

## 参考とした資料

ユーザー提供の ChatGPT 1.2026.251、Gemini 1.0.971139365、Grok 1.2.34-release.01 の XAPK を静的に確認した。
ChatGPT / Grok の文字列リソースには、添付失敗、送信の再試行、生成停止、検索状態、出典などの操作を示す文言が含まれていた。
これは機能や画面の実動作を確認した証拠ではない。Gemini の添付から会話画面の詳細は確認できなかった。
他社の実装や画像を転用せず、Chat Space 自体のコードで確認した問題を修正した。

## 変更

- 添付準備と送信準備を同期的にロックし、連打や同時の添付操作を防ぐ。準備中は入力・添付削除・モデル等の操作を無効化する。
- 添付読込みに失敗したファイルを個別に表示し、送信コールバックが拒否・失敗した場合は本文と添付を保持する。
- 会話ごとに入力コンポーネントの寿命を分離し、前の会話で開始した読込みの完了が別の会話への送信や表示に反映されないようにする。プライベートと新規会話も分離し、永続ストレージは追加しない。
- 日本語変換中の Enter を、composition 状態と keyCode 229 を含めて抑止する。
- 生成中は入力欄の送信ボタンを停止ボタンへ置換する。既存の停止処理を呼び出す。
- 追加ツールの高さを Radix が計算した空き領域と動的ビューポートに収め、内部をスクロール可能にする。
- モバイルの選択画面に明示的な閉じるボタンを追加する。
- 操作列と音声操作を折り返せるようにし、文字拡大で送信操作が画面外へ押し出される問題を修正する。主要操作のタップ領域を拡大し、音声状態を日本語に統一する。

## 検証の範囲

ローカル検証はフロントのコンポーネントと操作を対象とする。低いビューポートは実機のソフトキーボードそのものの検証ではない。
認証済みの本番会話、実際の LLM 生成、音声セッション、本番への反映はこのローカル検証に含まれない。
今回の送信保持は準備処理・送信コールバックの拒否や例外を対象とし、受理後の SSE 切断に対するサーバー側の再送・重複排除は変更していない。
会話切替時の入力は分離・リセットされる。複数会話の下書きを永続保存する機能は追加していない。
